### How it works

1. Pick a cryptocurrency.
2. Select its network, if there is more than one.
3. Scan the QR code or copy the address. Check the network before sending.

The page supports **BTC, ETH, USDT, USDC, BNB, SOL, XRP, TRX, TON, DOGE, LTC and XMR**. Everything is on one page, with no sign-in or tracking.

<details>
<summary>About this site</summary>

The site is a static page in [`dist/`](dist/). Its images and QR codes are stored in this repository; it does not need a backend or a CDN. It is published through the [GitHub Pages workflow](.github/workflows/pages.yml).

</details>
